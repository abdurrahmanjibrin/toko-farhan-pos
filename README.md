# toko-farhan-pos
ngebuat apps tokonya farhan albasyar untuk POS dan Inventory


### 🛒 Modul Utama Aplikasi Kasir
- **Point of Sale (POS)**: Pencatatan transaksi penjualan secara cepat dan akurat.
- **Inventory Tracking**: Pemantauan stok barang masuk dan keluar.
- **Laporan Penjualan**: Rekapitulasi histori transaksi harian.
